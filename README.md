# Finnish School – Introduction to mBot2

## What Is mBot2?

**mBot2** is an educational robot designed to help students learn programming, robotics, and technology.

It is used in ICT lessons to practise coding and understand how robots work.

## What Can mBot2 Do?

mBot2 can perform different actions by following instructions from a program.

It can:
- Move forward and backward.
- Turn left and right.
- Display information on its CyberPi screen.
- Change RGB LED colours.
- Detect objects and obstacles using sensors.
- Play sounds.

## What Is CyberPi?

**CyberPi** is the main controller of mBot2. It is a small programmable computer with a screen, buttons, sensors, and other features.

It allows us to write programs and control the robot.

## Three Important Features of mBot2

1. **CyberPi:** Controls the robot and displays information on its screen.
2. **Sensors:** Help the robot detect objects, light, and other conditions.
3. **RGB LEDs:** Produce different colours to make the robot more interactive.

## Why Do We Use mBot2 in ICT Lessons?

We use mBot2 because it helps us understand programming through practical activities.
We use mBot2 to learn *practical programming* and robotics.

It allows us to:
- Learn Python and block programming.
- Develop logical thinking.
- Understand how sensors work.
- Create different robot projects.
- Improve our problem-solving skills.

## My Learning Goals

1. Understand how mBot2 works.
2. Learn how to program the robot.
3. Use sensors and RGB LEDs.
4. Create my own robotics projects.
